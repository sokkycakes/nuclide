# User Preferences

Standing preferences distilled from `AGENTS.md`:

- Minimal reusable Nuclide framework (~3 monster archetypes via `monster_base`, MapC/RuleC goals) — not the full engine surface
- Prefer free/open rich UI; **WebCore CPU** over UltralightCore / heavy CEF; avoid paid-export tools (e.g. Rive)
- Prefer WebCore for in-game HUD as well as menus
- Mapless lobby when APIs allow
- Engine-side title-menu music playlist
- Canonical engine tree: [[fteqw-workspace]]
