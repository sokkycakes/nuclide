// (and so their .phy collision) are not installed. Bulwark reads it when it
// loads a Source BSP; a real models/<name>.phy always wins over it, and a
// maps/<map>.propclip file wins over this one for the models it names.
//
// One line per box, in the model's own space (x forward, y left, z up,
// origin at the model origin, Source units):
//   "<model>" box <min x> <min y> <min z> <max x> <max y> <max z>
// Repeat the line for more boxes. "<model>" none means no collision.
//
// Every size below is an estimate, not measured from the model. How each
// one was judged is in the comment above it (see also the Bulwark docs,
// docs/spec/vbsp.md, "Prop collision").
