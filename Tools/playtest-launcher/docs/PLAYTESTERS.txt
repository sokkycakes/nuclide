HOW TO PLAY THE PLAYTEST
========================

1. Unzip this folder anywhere you like (Desktop is fine).
2. Double-click the game's .exe in this folder.
3. The first time, it downloads the game. Wait for the bar to finish.
4. Press PLAY.

Every time you start it, it checks for a new build and downloads only
what changed, so you are always on the latest version.

Controller: D-pad or left stick to move, A to choose, B to quit.
Keyboard: arrow keys, Enter, Esc. The mouse works too.

If Windows shows "Windows protected your PC", click "More info" and then
"Run anyway". That happens because the launcher is new and not code-signed
yet; it only needs to be done once.

Something broken? Choose REPAIR GAME FILES. It checks every file and
re-downloads any that are damaged.

The game is installed in the "game" folder next to the launcher. To
uninstall, delete this whole folder.

HOSTING A SERVER
================

Quick game on your own machine: in the game, Create Lobby (LAN), or open
the console (~) and type for example
    g_gametype duel
    map duel_alley
Friends on the same network find it under Find Servers.

Dedicated server (no window, others connect to it). Open the "game"
folder next to the launcher, then:

  Windows:  double-click host-server.cmd
            (or run: fteqw64.exe -dedicated -basedir . -manifest base.fmf)
  Linux:    ./host-server.sh   in a terminal
            (or run: bulwark/bulwark-ded -basedir . -game base +map duel_alley,
             or:     bulwark/bulwark -dedicated -basedir . -game base +map duel_alley
             Run by hand like this, Bulwark starts no map unless you
             name one, so keep the +map.)

Settings (server name, player slots, game mode, time limit, password)
are in game/base/server.cfg. Updates never overwrite that file. Options
after the command win over it, for example:
    host-server.cmd -port 27600 +set g_gametype freezetag +map duel_alley
    ./host-server.sh -port 27600 +set g_gametype freezetag +map duel_alley

If you hosted before, your copy may still have a line that just says
    map duel_alley
near the end. Replace it with
    alias startmap_dm "map duel_alley"
Otherwise a server started with +map loads two maps in a row on
Windows. The new line still starts duel_alley when you name no map.

Type commands into the server window while it runs:
    status                  who is on, the map, the port
    serverinfo              the server's settings
    map duel_alley          change map (set g_gametype first to change mode)
    kick <name or slot>     remove a player
    addBot <name>           add a bot (names are in base/scripts/bots.txt)
    say <text>              message everyone
    password <word>         players then need: setinfo password <word>
    quit                    stop the server

Players join from the game's console with
    connect <server address>:27500
(27500 is the default port; open UDP 27500 on your router for players
outside your network). There is no public server list yet, so share the
address directly.
